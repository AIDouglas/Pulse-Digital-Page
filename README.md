# Proyecto Prepráctica

Base inicial organizada para la página web del proyecto.

## Estructura propuesta

- `index.html` → página principal.
- `assets/css/styles.css` → estilos globales y ajustes visuales.
- `assets/js/main.js` → interacciones, animaciones y lógica básica.
- `assets/img/` → imágenes locales del proyecto.
- `docs/` → documentación y planeación.

## Tecnología base

- HTML5
- Tailwind CSS por CDN para un desarrollo rápido y limpio
- JavaScript puro para la lógica y animaciones

## Paso a paso del proyecto

1. Definir la estructura general de la página.
2. Organizar la navegación y las secciones principales.
3. Separar estilos y scripts en archivos externos.
4. Ajustar la identidad visual del proyecto.
5. Colocar contenido real basado en la propuesta del anteproyecto.
6. Agregar imágenes, textos y llamadas a la acción.
7. Revisar responsividad y navegación en móvil.
8. Preparar la versión final para GitHub.

## Observación

Base inicial organizada simple.
