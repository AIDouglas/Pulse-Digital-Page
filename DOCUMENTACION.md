# Pulse Digital - Documentación del Proyecto

## 1. Introducción

### ¿Qué se quiere hacer?
Desarrollar un sitio web profesional para **Pulse Digital**, una empresa especializada en soluciones de marketing digital, atención al cliente y experiencias digitales. El objetivo es crear una plataforma que presente la empresa, comunique sus servicios y facilite el contacto con clientes potenciales.

### ¿Por qué se quiere hacer?
- **Presencia digital**: El 81% de los consumidores investigan empresas en línea antes de contactarlas (McKinsey, 2023)
- **Credibilidad**: Un sitio web profesional establece confianza con potenciales clientes
- **Conversión**: Facilita que visitantes se conviertan en clientes
- **Accesibilidad**: Debe funcionar en todos los dispositivos

## 2. Objetivos

### General
Crear un sitio web que comunique efectivamente la propuesta de valor de Pulse Digital y facilite la conversión de visitantes en clientes.

### Específicos
- Presentar los servicios principales de forma clara
- Implementar navegación intuitiva y responsiva
- Crear formulario de contacto funcional
- Optimizar para diferentes dispositivos
- Facilitar la interacción con la marca

## 3. Marco Teórico

### Diseño Responsivo
El proyecto utiliza principios de diseño responsivo que se adaptan a diferentes tamaños de pantalla. Se implementaron breakpoints en 320px, 768px, 1024px y 1280px+.

### UX/UI
Se aplicaron principios de experiencia de usuario:
- Claridad en la información
- Consistencia visual
- Navegación intuitiva
- Llamadas a la acción claras

### Accesibilidad
Se implementaron estándares básicos de accesibilidad WCAG 2.1 incluyendo contraste adecuado, textos alternativos en imágenes y navegación por teclado.

## 4. Metodología

### Tecnologías
- **HTML5**: Estructura semántica
- **CSS3 + Tailwind**: Estilos responsivos
- **JavaScript**: Interactividades (menú móvil, FAQ expandible)
- **Formspree**: Gestión de formularios de contacto

### Estructura
```
├── index.html          # Página principal
├── assets/
│   ├── css/styles.css  # Estilos personalizados
│   ├── js/main.js      # Lógica JavaScript
│   └── img/            # Imágenes y logos
├── Prepractica_Data/   # Datos y documentación
└── README.md
```

### Desarrollo
El proyecto se desarrolló de forma iterativa:
1. Estructura base y navegación
2. Secciones de contenido
3. Estilos y responsive design
4. Interactividades JavaScript
5. Optimización y pruebas
6. Integración de formularios
